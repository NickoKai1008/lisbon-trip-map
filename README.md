# Lisbon 2.5-Day Offline Route Map

里斯本 2026年9月1日至3日逐站行程、完整街图、天气与交通提醒。

## GitHub Pages 发布

1. 建立公开仓库 lisbon-trip-map。
2. 把本包内全部文件和文件夹上传到仓库根目录。
3. 打开 **Settings → Pages**。
4. Source 选择 **Deploy from a branch**，Branch 选择 **main** 和 **/(root)**。
5. 保存并等待 GitHub 显示 Pages 地址。

发布后的地址格式：

https://<你的GitHub用户名>.github.io/lisbon-trip-map/

## 离线使用

第一次需要联网。在 Safari 或 Chrome 打开网站后点击“保存离线”，等待两套街图下载完成；之后可添加到主屏幕。

## 内容

- Day 1：Baixa、The Folks Chiado、阿尔法马、Santo Amaro 大桥日落、Pinóquio 晚餐
- Day 2：热罗尼莫斯、贝伦、HIPPOtrip
- Day 3 上午：Cristo Rei
- 海岸备选：Cascais、地狱之口、罗卡角、Azenhas do Mar

地图数据来自 OpenStreetMap / Protomaps。仓库不包含姓名、电话、订单号或住宿地址。
