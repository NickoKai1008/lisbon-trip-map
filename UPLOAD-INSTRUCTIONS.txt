里斯本 GitHub Pages 上传说明
============================

仓库名称（Repository name）：lisbon-trip-map
仓库标题：Lisbon 2.5-Day Offline Route Map
仓库描述（Description）：里斯本 2026年9月1日至3日逐站行程、完整街图和离线交通提醒
可见性：Public

上传步骤：
1. 登录 https://github.com/new
2. Repository name 填 lisbon-trip-map，选择 Public，点击 Create repository。
3. 解压 lisbon-github-pages.zip；不要上传 ZIP 本身。
4. 在新仓库点击 Add file → Upload files，把解压后的全部文件和文件夹拖进去，提交到 main。
5. 打开 Settings → Pages，在 Build and deployment 选择 Deploy from a branch。
6. Branch 选择 main，目录选择 /(root)，点击 Save。

通常等待 1–5 分钟后访问：
https://<你的GitHub用户名>.github.io/lisbon-trip-map/

手机首次使用：
用 Safari 打开链接 → 点击“保存离线” → 等待显示“已保存离线” → 分享 → 添加到主屏幕。

重要：两个 maps/*.pmtiles 文件必须原样上传；缺少任何一个，街图都会不完整。
